# LightBWS v0.2.7

## Administration without the detours

- Start from **Create new** in navigation or a resource page. Secrets, projects, application identities, users, and groups share the same creation workflow.
- After creating a project, add a secret with the project already selected or configure access without switching pages. Optional follow-up steps do not roll back an already-created resource.
- Create a project inside the secret form while preserving the secret's key, value, and note. The new project is saved immediately and selected automatically.
- Open a project to view its secrets, filter by project, and share a project-scoped URL. **All secrets** returns to the complete list.
- Configure a new machine account's access without discarding its one-time token. Tokens remain in memory only and disappear when the flow closes.
- Add group members directly after group creation.

## Interaction and layout

- Navigation follows daily work, access control, operations, and support rather than the order features were added.
- A modal mobile drawer supports Escape, keyboard focus containment, root/body background scroll locking, and automatic cleanup on desktop resize. Shared locks also handle nested dialogs without leaking scroll state.
- Responsive search/project filters, consistent control alignment, larger touch targets, safe-area spacing, and long-name wrapping improve phone, tablet, and desktop use.
- Shared 160–200ms press/layer feedback uses transform and opacity. Keyboard actions are immediate; reduced-motion, reduced-transparency, and high-contrast preferences are respected.

## Dependencies

- Update compatible frontend and Rust dependencies and regenerate both Cargo lockfiles and the npm lockfile.
- Retain the Rust 1.94 minimum supported version, existing Astryx theme APIs, and backend/SDK protocol contracts.
- No database schema changes or data migration are required.

## Known SDK demo limitation

The standalone SDK demo depends on the upstream Bitwarden SDK, which still brings in `rsa` affected by `RUSTSEC-2023-0071` (RSA timing side channels). The advisory has no patched version. The LightBWS server does not depend on this crate, and the demo is not bundled into the server release. Do not repurpose the demo as a network-exposed RSA service. The advisory is not suppressed in the demo dependency audit.
